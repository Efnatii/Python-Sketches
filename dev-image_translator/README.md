# dev-image_translator

Небольшой инструмент для быстрого перевода текста, отображаемого на экране.

## Как это работает

1. Нажмите `CTRL+ALT` и выделите область на экране.
2. Скрипт делает снимок, распознаёт текст через Tesseract и переводит его.
3. Перевод появляется в небольшом окне рядом с курсором.

## Требования

- Windows (используется WinAPI через `pywin32`). Для размытия фона нужна Windows 10+.
- Tesseract OCR. Путь можно задать аргументом `--tesseract-path` или переменной `TESSERACT_CMD`.
- Зависимости из `requirements.txt`.

Установите их командой:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python image_translator.py
```

Для вывода каждого снятого скриншота используйте режим отладки:

```bash
python image_translator.py --debug
```

Запустите скрипт, удерживайте `CTRL`+`ALT` и выделите область с текстом.
После распознавания перевод появится поверх остальных окон.
Скриншоты сохраняются в каталог `screenshots` (файл `screenshot.bmp` по умолчанию).
