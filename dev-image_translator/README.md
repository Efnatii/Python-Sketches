# dev-image_translator

Этот подпроект представляет собой небольшой инструмент для быстрого перевода текста, отображаемого на экране.

## Как это работает

1. Запускается скрипт `image_translator.py`.
2. Пользователь нажимает и удерживает комбинацию `CTRL+ALT`, перемещая курсор для выделения прямоугольной области на экране.
3. Выбранная область сохраняется как изображение и передаётся в OCR (pytesseract).
4. Распознанный английский текст переводится на русский с помощью библиотеки `translate`.
5. Переведённый текст отображается в небольшом окне возле курсора мыши. Окно прозрачно и следует за курсором, пока пользователь не начнёт новое выделение.
6. Текст плавно появляется в окне, а выбранная область подсвечивается полупрозрачным прямоугольником.
7. Фон позади окна размывается средствами Windows (blur behind), что улучшает читаемость текста.
8. Окно поддерживает полу-прозрачный фон благодаря использованию флагов `LWA_COLORKEY` и `LWA_ALPHA`.

## Требования

- Windows (используется WinAPI через `pywin32`).
- Для размытия фона требуется Windows 10 или новее.
- Установленный Tesseract OCR. По умолчанию путь к исполняемому файлу ожидается `C:\\Program Files\\Tesseract-OCR\\tesseract.exe`.
- Python‑пакеты из файла `requirements.txt`.

Установите их командой:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python image_translator.py
```

Для вывода каждого снятого скриншота используйте режим отладки:

```bash
python image_translator.py --debug
```

После запуска одновременно нажмите `CTRL` и `ALT` и, не отпуская их, выделите область с текстом. Когда клавиши будут отпущены, скрипт распознает текст, переведёт его и выведет результат поверх остальных окон.

Скриншоты сохраняются в каталог `screenshots` (по умолчанию файл `screenshot.bmp`).
